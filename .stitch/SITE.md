## 1. Site Vision & Narrative

Anvaya is an elite, engineering-first software and AI systems studio. The website delivers an Awwwards-caliber, deterministic developer experience with zero agency fluff:
- High contrast, razor-sharp architectural layout with hairline precision borders (`border-white/10`).
- Fully customizable color harmony, focal accents, and interactive energy glows.
- Interactive, tactile proof-of-work developer cockpits and telemetry diff engines.
- Uncompromising 60fps performance and sub-1.5s LCP.

## 5. Development Roadmap (Sequential Baton Loop)

1. **Sprint 01: Hero Monolith & Pinned Cockpit Drawer**
   - Baton: `.stitch/next-prompt.md`
   - Target: Preloader animation (`useGSAP()`) + Hero typographic punch + resting cockpit drawer.
2. **Sprint 02: Ticker Ribbon & Systems Over Slop Bento**
   - Seamless GSAP horizontal loop + Bento cards with radial cursor lighting.
3. **Sprint 03: The Sprint Protocols (3D Perspective Tilt)**
   - Monolithic cards for 14-Day MVP, Neural Core, and Hardened Edge.
4. **Sprint 04: Interactive Proof-of-Work Terminal & AST Diff Simulator**
   - Tabbed macOS developer container with interactive code morphing.
5. **Sprint 05: Verified Testimonials & Ledger FAQ**
   - Verified commit badges and spring-animated accordions.
6. **Sprint 06: Monolithic Footer & Dynamic Intake Modal**
   - Display wordmark reveal + Cal.com scheduling embed.
