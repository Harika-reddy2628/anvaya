## 🎯 The Mission
Quantum mechanics is not abstract blackboard misery—it is **spatial 3D sphere geometry**. 

In classical computing, a bit is a dead light switch: either `0` or `1`. In quantum computing, a **qubit** is a vector that can point to **any spot on the surface of a 3D ball (The Bloch Sphere)**. 

In this mission, you will see and control a real quantum superposition with your own hands.

---

## 🛠️ Step-by-Step Execution Guide

### Step 1: Open the Interactive Quantum Sandbox (5 mins)
1. Open your web browser and go to: **[algassert.com/quirk](https://algassert.com/quirk)**.
2. This is **Quirk**, a drag-and-drop quantum circuit simulator.
3. Look at the bottom right: you will see a 3D sphere called the **Bloch Sphere**. The blue arrow is currently pointing straight up to $|0\rangle$.

---

### Step 2: The Quantum Magic Trick — The Hadamard Gate (10 mins)
1. In the gate toolbox at the top, look for the green **`H`** box (The Hadamard Gate).
2. Drag the **`H`** gate onto the very first wire (Wire 0).
3. **Look at the Bloch Sphere at the bottom:**
   * The arrow was pointing straight UP (North Pole: 100% chance of 0).
   * After the $H$ gate, the arrow rotates $90^\circ$ onto the **Equator**!
   * Look at the measurement probability bar: It now reads **50% Chance of 0, 50% Chance of 1**.
4. **The Intuition:** The qubit is not 0 and not 1. It is in a continuous rotation between them until you measure it. This is **Quantum Superposition**.

---

### Step 3: Run True Quantum Code in Python (10 mins)
Now let's run this in Python:
1. Install Qiskit:
   ```bash
   pip install qiskit qiskit-aer
   ```
2. Create `quantum_flip.py`:
   ```python
   from qiskit import QuantumCircuit
   from qiskit_aer import AerSimulator

   # 1. Create a quantum circuit with 1 qubit and 1 classical bit
   qc = QuantumCircuit(1, 1)

   # 2. Apply Hadamard gate: rotates the qubit onto the sphere's equator!
   qc.h(0)

   # 3. Measure: Forces the universe to choose 0 or 1
   qc.measure(0, 0)

   # 4. Simulate 1,000 runs
   simulator = AerSimulator()
   job = simulator.run(qc, shots=1000)
   counts = job.result().get_counts()

   print("✨ Quantum Measurement Results across 1,000 trials:")
   print(counts)
   print(f"Probabilities: Zero = {counts.get('0', 0)/10:.1f}%, One = {counts.get('1', 0)/10:.1f}%")
   ```
3. Run:
   ```bash
   python quantum_flip.py
   ```
* **Success Gate:** You see near-perfect 50/50 probability distribution (e.g., `{'0': 503, '1': 497}`) generated by a simulated quantum state vector!

**Mission Complete!** You have demystified quantum computing and written your first real quantum circuit.
