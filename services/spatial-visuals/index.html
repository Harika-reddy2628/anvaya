02 — WHAT WE SOLVE

Before a space is built, it still needs to be believed in.

A plan can be accurate and still be difficult to imagine. We help architects, interior teams, developers and homeowners see the feeling, flow and character of a space before expensive decisions are made.

Let’s find the right starting point↗

03 — OUR APPROACH

Read the brief. Shape the atmosphere. Refine the detail.

One clear direction, from the first conversation to the finished work.

  1. 01

    Read the space

    Understand the plan, orientation, function and people using it.

  2. 02

    Set the direction

    Establish the materials, lighting and visual mood.

  3. 03

    Build the view

    Model the key spaces and perspectives.

  4. 04

    Refine what matters

    Improve the details that make the visual believable.
